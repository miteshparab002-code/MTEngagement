 MITESH & TANVI — ENGAGEMENT INVITATION

Files
- index.html: complete, self-contained invitation page (CSS and JavaScript are embedded).
- style.css: standalone copy of the page styles.
- script.js: standalone copy of the page interactions.

Preview
Open index.html in a browser. It does not depend on style.css or script.js being present,
so the design remains intact when index.html is previewed by itself.

GitHub Pages
1. Extract this ZIP.
2. Upload all four files directly into the root of your GitHub repository
   (not inside an extra nested folder).
3. Commit the files and enable GitHub Pages from Settings > Pages.
4. Open the published site URL after deployment completes.

The Google Fonts link requires an internet connection; fallback fonts are provided.
